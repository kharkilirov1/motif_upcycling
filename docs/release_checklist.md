# Release checklist

- [ ] Run `pytest -q`.
- [ ] Run exactness smoke tests with and without SARC.
- [ ] Verify trainable parameter counts.
- [ ] Publish paper PDF and source.
- [ ] Add model-card metadata if uploading adapters to Hugging Face.
- [ ] Do not claim universal validity, frontier quality, or long-context robustness without separate eval.

Suggested first GitHub release tag: `v0.1.0`.
